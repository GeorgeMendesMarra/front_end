Programação Web I

HTML + CSS + JavaScript

Como as tecnologias se conectam?

HTML estrutura, CSS apresenta e JavaScript adiciona comportamento.

HTML
→
CSS
→
JavaScript

HTML → CSS

O HTML referencia o CSS através da tag <link>. 

<link rel="stylesheet" href="style.css">

Como o CSS encontra os elementos HTML?

Se o HTML possui id="cabecalho", o CSS pode usar #cabecalho.

Se o HTML possui class="titulo", o CSS pode usar .titulo.

HTML → JavaScript

O JavaScript pode localizar elementos HTML usando seus ids.

Resumo da conexão

  • HTML: cria a estrutura e os elementos.
  • CSS: seleciona elementos e define aparência.
  • JavaScript: acessa o DOM e modifica o comportamento.
