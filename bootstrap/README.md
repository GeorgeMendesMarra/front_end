# Bootstrap: exemplos didáticos

Exemplos em ordem crescente de dificuldade para Programação Web I.
Basta abrir cada arquivo `.html` no navegador (é preciso internet, pois o Bootstrap vem de um CDN).

| Arquivo | O que ensina |
|---|---|
| `01-primeiros-passos.html` | Instalação via CDN, navbar, container, botões, alertas e utilitários |
| `02-grid-e-cards.html` | Sistema de 12 colunas, breakpoints (`col-md-*`, `col-lg-*`) e cards |
| `03-formulario.html` | Campos de formulário, `select`, radio, checkbox e validação |
| `04-landing-page.html` | Projeto completo juntando tudo: navbar, hero, grid, contato e rodapé |

## Atividades sugeridas
1. Mude as cores dos botões trocando `btn-primary` por `btn-success`, `btn-danger` etc.
2. Redimensione a janela e observe o grid mudando de 3 para 2 e 1 coluna.
3. Adicione um quarto card no exemplo 2.
4. Crie sua própria landing page com outro tema, a partir do exemplo 4.

Documentação oficial: https://getbootstrap.com/docs/5.3
