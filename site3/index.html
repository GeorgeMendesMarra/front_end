TECNOLOGIAS

HTML + CSS + JavaScript

As três tecnologias continuam separadas por responsabilidade, mas trabalham em conjunto para construir a interface.

HTML

Estrutura

Cria títulos, parágrafos, links, seções, botões, formulários e demais elementos da página.

CSS

Apresentação

Controla cores, espaçamentos, tipografia, layout, estados visuais, responsividade e aparência do menu.

JS

Comportamento

Controla o menu, eventos de clique, navegação, estado visual e mensagens exibidas dinamicamente.

HTML → CSS → JavaScript → Interface Web
