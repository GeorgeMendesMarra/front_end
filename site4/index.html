JQUERY NA PRÁTICA

Três exemplos simples de jQuery

Cada cartão abaixo demonstra um recurso básico do jQuery: selecionar elementos, escutar eventos e aplicar efeitos visuais com poucas linhas de código.

$( )

Selecionar e exibir

Usa $("#id") para selecionar um elemento e os métodos .fadeOut() / .fadeIn() para trocar o texto com uma transição suave.

.on( )

Curtir com jQuery

Usa .on("click", ...) para escutar o clique e .toggleClass() para alternar o estado visual do botão de curtir.

Curtidas: 0

.each( )

Tema claro e escuro

Usa .toggleClass() na tag body para alternar entre o tema claro e o tema escuro de toda a página.

Perguntas frequentes (acordeão com .slideToggle())

É uma biblioteca JavaScript que simplifica a seleção de elementos, os eventos e as animações usando uma sintaxe curta baseada no símbolo $.

Por meio de uma tag <script> apontando para um CDN, colocada antes do arquivo script.js, para que o $ já esteja disponível.

Não. O jQuery é escrito em JavaScript e roda sobre ele; apenas oferece funções prontas para tarefas comuns, como as vistas nos Sites 1, 2 e 3.

TECNOLOGIAS

HTML + CSS + JavaScript + jQuery

O jQuery se soma às tecnologias anteriores, mas continua dependendo do HTML para estrutura e do CSS para aparência.

HTML

Estrutura

Cria títulos, parágrafos, links, seções, botões e demais elementos da página.

CSS

Apresentação

Controla cores, espaçamentos, tipografia, layout, temas e responsividade.

JS

Comportamento

É a linguagem sobre a qual o jQuery é construído; continua controlando a lógica da página.

jQ

Produtividade

Simplifica seletores, eventos e efeitos, reduzindo a quantidade de código JavaScript necessária.

HTML → CSS → JavaScript → jQuery → Interface Web
